# GitHub Hardening Checklist

## Repository Security

- Enable dependency graph
- Enable Dependabot alerts
- Enable secret scanning
- Enable push protection

## Publication Safety

- confirm no raw PDFs are tracked
- confirm no populated env files are tracked
- confirm processed outputs keep source lineage references
- confirm reviewer identifiers are pseudonymous

## Ongoing Maintenance

- keep methodology and data-policy docs in sync with pipeline changes
- keep attribution text current when upstream lineage changes
