# Security

This project is public. If you find a security issue, do not post it in public issues.

Report security concerns through GitHub's private reporting channel.
- Open a new issue and mark it confidential using "Report a vulnerability"
  if that flow exists for this repo.

Use normal issue templates for non-sensitive quality and reliability problems.

For all disclosures, include:
- package and version;
- exact reproduction steps;
- commands run and environment details.
