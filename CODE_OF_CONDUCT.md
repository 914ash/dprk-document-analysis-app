# Contributor Code of Conduct

Keep this project welcoming and respectful.

## Expected behavior

- Be constructive and specific.
- Respect privacy and avoid speculation about real-world identities.
- Treat public contributors as collaborators regardless of background or experience.
- Keep criticism focused on code, data quality, and reproducibility.

## Unacceptable behavior

- Personal attacks, harassment, or discriminatory conduct.
- Doxing, privacy abuse, or non-consensual disclosure.
- Flooding discussions with low-effort noise.

## Enforcement

Report violations to the repository maintainers.
Reporters should expect follow-up context questions.
Do not expose sensitive intelligence or private information in public channels.
