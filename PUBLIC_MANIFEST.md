# Public Manifest

This repository is intended for public publication.

## Included

- dashboard, entity-resolution, and network-drift source code
- methodology, lineage, and data-policy docs
- generated public visuals for portfolio review

## Excluded

- raw PDFs and non-public source archives
- local runtime logs and private analysis artifacts
- populated env files and credential-bearing config

## Attribution

This repo reuses and extends RAND Corporation lineage (`black-knights-and-dark-network`) and keeps upstream provenance explicit in docs and output conventions.
