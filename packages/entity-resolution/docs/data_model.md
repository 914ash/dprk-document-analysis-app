# Data Model

All tables are stored in LanceDB at `data/processed/lancedb/`. Review decisions are written to `data/review/decisions.parquet`.

---

## Table: `documents`

Ingestion metadata for each report PDF.

| Field | Type | Description |
|-------|------|-------------|
| `doc_id` | `str` | Primary key. UN document symbol (e.g. `S-2024-171`) |
| `title` | `str` | Report title |
| `report_date` | `str` (ISO date) | Publication date of the report |
| `report_type` | `str` | `final` or `midterm` |
| `source_url` | `str` | Canonical UN Documents URL |
| `checksum` | `str` | SHA-256 hex digest of the local PDF file |
| `page_count` | `int` | Number of pages extracted |
| `ingested_at` | `str` (ISO datetime) | UTC timestamp when the record was created |

---

## Table: `mentions`

Entity mentions extracted from report text, including vector embeddings.

| Field | Type | Description |
|-------|------|-------------|
| `mention_id` | `str` | Primary key (UUID4) |
| `doc_id` | `str` | Foreign key → `documents.doc_id` |
| `page` | `int` | Page number within the source PDF |
| `surface_form` | `str` | Raw entity text as it appears in the document |
| `normalized_form` | `str` | Cleaned/title-cased form used for comparison |
| `entity_type` | `str` | `ORG`, `PERSON`, `VESSEL`, or `LOCATION` |
| `context_left` | `str` | Up to 50 characters of text preceding the mention |
| `context_right` | `str` | Up to 50 characters of text following the mention |
| `chunk_text` | `str` | Full text chunk the mention was extracted from |
| `embedding` | `list[float]` | Sentence-transformer vector (384-dim for all-MiniLM-L6-v2) |
| `model_name` | `str` | Name of the embedding model used |
| `created_at` | `str` (ISO datetime) | UTC timestamp when the record was created |

---

## Table: `candidate_pairs`

Proposed alias pairs generated by the resolution engine.

| Field | Type | Description |
|-------|------|-------------|
| `candidate_id` | `str` | Primary key (UUID4) |
| `mention_id_a` | `str` | Foreign key → `mentions.mention_id` (first mention) |
| `mention_id_b` | `str` | Foreign key → `mentions.mention_id` (second mention) |
| `score` | `float` | Combined similarity score in [0, 1] |
| `reasons` | `list[str]` (JSON) | Human-readable list of reasons the pair was proposed |
| `status` | `str` | `pending`, `approved`, or `rejected` |

---

## Table: `candidate_clusters`

Provisional entity clusters built from transitive closure of candidate pairs.

| Field | Type | Description |
|-------|------|-------------|
| `cluster_id` | `str` | Primary key (UUID4) |
| `member_mentions` | `list[str]` (JSON) | Ordered list of `mention_id` values in this cluster |
| `cluster_score` | `float` | Mean pairwise score across member pairs |
| `status` | `str` | `pending`, `approved`, or `rejected` |

---

## Table / File: `review_decisions`

Analyst decisions on candidate pairs. Stored as `data/review/decisions.parquet`.

| Field | Type | Description |
|-------|------|-------------|
| `decision_id` | `str` | Primary key (UUID4) |
| `candidate_id` | `str` | Foreign key → `candidate_pairs.candidate_id` |
| `reviewer` | `str` | Reviewer identifier (`pipeline`, `analyst-001`, etc.) |
| `decision` | `str` | `approved`, `rejected`, or `needs_review` |
| `notes` | `str` | Free-text analyst notes |
| `model_version` | `str` | Embedding model version at decision time |
| `created_at` | `str` (ISO datetime) | UTC timestamp when the decision was recorded |

---

## Supporting Type: `TextChunk`

Intermediate record produced by `ParseService`, stored in `data/interim/chunks.parquet`.

| Field | Type | Description |
|-------|------|-------------|
| `chunk_id` | `str` | Primary key (UUID4) |
| `doc_id` | `str` | Foreign key → `documents.doc_id` |
| `page` | `int` | Page number within the source PDF |
| `text` | `str` | Extracted page text |
| `created_at` | `str` (ISO datetime) | UTC timestamp when the chunk was created |

---

## Supporting Type: `ManifestRow`

One row from `data/raw/manifest.csv`.

| Field | Type | Description |
|-------|------|-------------|
| `doc_id` | `str` | Document identifier |
| `title` | `str` | Human-readable title |
| `report_type` | `str` | `final` or `midterm` |
| `report_date` | `date` | Publication date |
| `source_url` | `str` | Canonical URL |
| `mirror_url` | `str` | Optional mirror URL |
| `local_path` | `str` | Relative path to local PDF |
| `checksum` | `str` | SHA-256 after download |
| `status` | `str` | `pending`, `fetched`, `parsed`, or `failed` |
